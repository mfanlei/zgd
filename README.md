# zgd-代码说明以及物理图景

本仓库包含 ZGD（Z-几何动力学）理论系列论文的核心验证数值代码。所有代码均基于公开观测数据编写，依赖标准科学计算库（NumPy、SciPy、Matplotlib 等），运行方式为 `python <文件名>.py`。

## 一、 核心代码与论文对应关系

### 1. 并合星系团验证（论文一 §3.1–§3.2）

*   **`bullet01a.py`** — 双 \(\beta\) 模型 ZGD 有效引力场计算，输出透镜峰偏移量、物理根源验证数据及可视化图表。
*   **`bullet_newton_only01.py`** — 纯牛顿对照组，关闭几何修正项，用于量化其独立贡献。

### 2. 星系旋转曲线验证（论文一 §4.2–§4.7）
*   **`sparc09.py`** — 读取 SPARC 质量模型，计算渐近探针的整体偏移量（+12.5%），并生成速度散点图与直方图（`sparc_zgd_validation.png`）。*（注：此脚本同时也输出了未扣除重子项的纯速度比值违反数 30/175，作为早期探索。论文中严格的上界定理检验以 `sparc17.py` 为准。）*
*   **`sparc17.py`** — 严格的上界定理操作化检验脚本。扣除了重子项（\(V_{\text{bar}}\)），计算残余几何场代理 \(\eta\)，输出最终的 10/175 违反数。同时生成点质量高估量的 L 型断层图（`sparc_delta_overestimation.png`）。
*   **`c_q_verification.py`** — **核心脚本**。执行 \(C_{\text{ours}}\)、纯几何重整标度 \(g\) 以及 RAR 精确插值的代数分离对比。生成 `c_q_verification.png`，论证 \(C_{\text{ours}} = q + g\) 的代数假象，并展示 \(g\) 的环境依赖提示性梯度（深端 0.66，盘星系 0.58）。

### 3. 星系团核心引力透镜（论文一 §4.8 与附录 B）
*   **`bcgicm.py`** — 构建双成分质量模型（BCG 用 Hernquist，ICM 用 \(\beta\) 模型），执行 BCG/ICM 质量比扫描，生成 `lensing_mass_ratio_scan.png`。
*   **`bcgicm_fbar_scan.py`** — 针对不同重子分数（\(f_{\text{bar}} = 0.05, 0.10, 0.20\)）进行多线扫描。结果表明，真实富团核心（\(f_{\text{bar}} \sim 0.05\)）在质量比 \(\sim 0.03\) 处能够完美填补透镜缺口（填补率 \(\sim 1.0\)）。生成 `lensing_fbar_scan.png`。

### 4. 非线性场方程三维正演（论文一 附录 C）

*   **`zgd_galaxy_3d_fft.py`** — 利用快速傅里叶变换（FFT）迭代求解 \(p=3\) 拉普拉斯方程。模拟盘星系与外部弥散晕的相互作用，证明非线性通量重分配与等势面拓扑重构。生成 `zgd_3d_slice_highres.png`。

### 5. 宇宙学 DESI DR2 拟合与检验（论文一 §5）

*   **`step1.py` — `step4.py`** — 论文一的双幂律唯象拟合。
*   **`caijue.py`** — 用于复现论文一宇宙学部分对 DESI DR2 BAO 数据的全部关键数值。
    *   **注意**：需与官方数据文件 `desi_gaussian_bao_ALL_GCcomb_mean.txt` 和 `desi_gaussian_bao_ALL_GCcomb_cov.txt` 放在同一目录。

### 6. 近场哈勃常数检验（附篇）

*   **`habo01.py`** — 利用 Cosmicflows-4 星系群数据，逐天区测量局部哈勃常数，检验与物质密度的负相关性。
    *   **注意**：需使用数据文件 `table3.bat`（来源：CDS）。

## 三、 几个可供分享的物理图景

**1. 暗能量的“橡皮筋”比喻**
暗能量就像一根均匀弥漫的橡皮筋——它拉远星系（驱动宇宙膨胀），也同时拉长引力的有效作用范围（解释星系旋转曲线平坦化）。在 ZGD 中，暗能量不是超距作用，而是作用于整体空间的几何背景。

**2. 为什么 \(a_0\) 必然存在？**
视界面以光速向外退行，光从宇宙深处赶来，在追赶中累积的时间延迟，等效于一个背景加速度 \(a_0 = c^2/R_p\)。这不是某个物体在加速，而是宇宙因果边界本身的属性。**光速有限 + 宇宙年龄有限 = \(a_0\) 必然存在**（光永远追不上视界，所以等效的“加速度”恒在）。

**3. MOND 常数的真相：混合表象与环境稀释**
在标准 MOND 中，经验常数 \(a_0 \approx 1.2 \times 10^{-10} \text{ m/s}^2\) 是一个谜。ZGD 的代数分离（\(C_{\text{ours}} = q + g\)）表明，MOND 常数并非基本常数，而是**客观存在的重子项（\(q\)）**与**被宇宙网环境稀释后的几何项（\(g\)）**在速度平方上的混合产物。纯几何重整标度 \(g\) 在深端孤立矮星系中接近 0.66，在环境稠密的盘星系中降至 0.58。正是这种非线性介电屏蔽效应，造就了星系外围平坦的旋转曲线。

**4. 并合星系团的“暗物质晕”**
并合星系团中观测到的所谓“暗物质晕”偏移，与普通星系的“暗物质晕”本质上是一样的，都是非线性几何修正场在密度过渡带和视线路径积分中的投影。ZGD 的数值扫描表明，透镜缺口的填补比例极其敏感于核心质量集中度（BCG/ICM 比），这与标准冷暗物质模型中晕质量的平滑分布预期形成了鲜明的判别。
